Official personal website and portfolio for **symplelx**, built with clean, modern web technologies, zero heavy frameworks, and a strong focus on performance and minimalist design.

---

## 🚀 Features

- **Modular Architecture:** Clean separation of concerns with dedicated markup, styling, and logic scripts.
- **Dark / Light Theme Toggle:** Instant theme switching with preference persistence using browser `localStorage` (defaults to dark mode).
- **Fully Responsive:** Fluid layout optimized for mobile devices, tablets, and desktop displays.
- **Modern CSS:** Built using CSS Custom Properties (`:root`), Flexbox, and smooth hardware-accelerated transitions.
- **High Performance:** Lightweight static site hosted on GitHub Pages with Cloudflare CDN integration and SSL/TLS encryption.
