O mnie

Jestem uczniem 4. klasy technikum o profilu programistycznym w Zespole Szkół Technicznych i Licealnych w Piechowicach. Moja przygoda z programowaniem opiera się na ciągłym dążeniu do tworzenia wydajnych, skalowalnych i nowoczesnych aplikacji webowych oraz mobilnych. Posiadam solidne fundamenty praktyczne, co potwierdza mój wynik 100% z części praktycznej państwowego egzaminu zawodowego.

W codziennej pracy skupiam się na pisaniu czystego kodu, optymalizacji wydajności oraz poznawaniu nowoczesnych architektur oprogramowania. Tworzę zarówno kompleksowe systemy backendowe w Pythonie i PHP, jak i interaktywne interfejsy frontendowe w React. Obecnie intensywnie rozwijam swoje kompetencje w obszarze tworzenia natywnych aplikacji mobilnych na system Android (kwalifikacja INF.04), budując pełne ekosystemy łączące REST API z aplikacjami mobilnymi.

Kwalifikacja INF.03 — Tworzenie i administracja stronami i aplikacjami internetowymi

Fundamenty web developmentu, systemy bazodanowe oraz narzędzia wykorzystywane w projektach internetowych:

Narzędzia i Aplikacje

Oprogramowanie wspomagające tworzenie i wdrażanie stron

  • Visual Studio / VS Code: Główny, wszechstronny edytor kodu z bogatym zestawem rozszerzeń do pisania kodu HTML, CSS, JS i PHP.
  • WordPress & WooCommerce: Popularny system CMS oraz platforma e-commerce do stawiania profesjonalnych stron i sklepów internetowych.
  • FileZilla: Klient FTP/SFTP wykorzystywany do szybkiego przesyłania plików projektowych i zarządzania zasobami na serwerze zdalnym.
  • XAMPP / phpMyAdmin: Lokalny pakiet serwerowy (Apache, MySQL) do uruchamiania skryptów PHP i zarządzania relacyjnymi bazami danych.

Języki Programowania i Bazy

Technologie i składnia opanowane w ramach INF.03

  • HTML5 & CSS3: Semantyczna struktura dokumentów, zaawansowane stylowanie (Flexbox, Grid) oraz w pełni responsywny layout (RWD).
  • JavaScript (ES6+): Skryptowy język przeglądarkowy do interakcji z użytkownikiem, asynchroniczności (Fetch API) i manipulacji DOM.
  • PHP: Język backendowy do obsługi formularzy, sesji, ciasteczek oraz budowania logiki serwerowej stron.
  • SQL (MySQL): Tworzenie tabel, relacji, indeksów oraz pisanie wydajnych zapytań SQL i procedur składowanych.
  • Python: Podstawy języka oraz pisanie skryptów automatyzujących i prostych narzędzi konsolowych.

Kwalifikacja INF.04 — Projektowanie, programowanie i testowanie aplikacji mobilnych

Zaawansowane aplikacje, frameworki webowo-mobilne, systemy kontroli wersji oraz języki programowania:

Narzędzia, Aplikacje & Frameworki

Środowiska deweloperskie i biblioteki do zaawansowanych projektów

  • Git & GitHub: System kontroli wersji do śledzenia zmian w kodzie, zarządzania gałęziami oraz zespołowej publikacji projektów.
  • Flask: Lekki mikroframewok w Pythonie służący do szybkiego tworzenia lekkich mikroserwisów i REST API.
  • Django & Django REST: Potężny framework Pythonowy oraz moduł REST API do budowania bezpiecznego zaplecza i komunikacji z aplikacjami.
  • React: Biblioteka JavaScript służąca do tworzenia nowoczesnych, dynamicznych interfejsów użytkownika i aplikacji typu SPA.
  • Android Studio & Jetpack Compose: Profesjonalne środowisko IDE dla deweloperów Androida wraz z nowoczesnym, deklaratywnym toolkitem UI.
  • BlueStacks 5: Wydajny emulator i platforma testowa do uruchamiania i sprawdzania aplikacji mobilnych.

Języki Programowania

Języki, w których koduję i rozwijam oprogramowanie

  • Java: Klasyczny język obiektowy używany m.in. do tworzenia aplikacji mobilnych na system Android oraz logiki backendowej.
  • Kotlin: Nowoczesny, w pełni wspierany przez Google język dla platformy Android, zapewniający zwięzłość i bezpieczeństwo kodu.
  • Python: Zaawansowane wykorzystanie w backendzie (Django, Flask), algorytmach i automatyzacji zadań.
  • C# & C++: Znajomość podstaw i paradygmatów programowania obiektowego, logiki proceduralnej oraz zarządzania pamięcią.
  • XML: Język znaczników używany do projektowania strukturalnych layoutów ekranów w aplikacjach mobilnych na Androida.
  • TypeScript: Nadzbór języka JavaScript wprowadzający silne typowanie statyczne, wykorzystywany w nowoczesnym web devie.
